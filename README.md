# 福岡市イベントMAP

福岡市政だより（令和8年10月1日号）をもとにした個人用イベントMAPです。

## 公開方法（GitHub Pages）

1. GitHubで新しいRepositoryを作成
2. Repository名は `fukuoka-event-map` など任意
3. このフォルダ内の `index.html` と `.nojekyll` をRepositoryの直下へアップロード
4. GitHubの **Settings → Pages**
5. **Build and deployment / Source** を `Deploy from a branch`
6. Branchを `main`、Folderを `/ (root)` にして保存
7. 数分後に表示されるURLをスマホで開く

URL例：
`https://YOUR-ACCOUNT.github.io/fukuoka-event-map/`

## スマホ
ブラウザの「ホーム画面に追加」を使えば、アプリのように起動できます。

## 注意
会場位置は表示用の概略位置です。日程・料金等は原紙／福岡市公式情報をご確認ください。
